
# 🪽Parang-Sê 
## []  풍경이 되는 단 하나의 프레임    
### 프리미엄 하우징 브랜드 **Parang-Sê**는 1908년 벨기에의 상징주의 거장이자 1911년 노벨 문학상 수상자인 **모리스 마테를링크(Maurice Maeterlinck)** 의 명작 희곡, 《파랑새(L'Oiseau bleu)》의 인문학적 서사에 모티브를 둡니다.

* **서사의 철학적 재해석**: 주인공 남매가 행복(파랑새)을 찾아 폭풍우와 밤의 궁전을 헤매는 여정 끝에 결국 자신의 집(Home)에서 파랑새를 발견하듯, **"인간이 누릴 수 있는 최상의 안식과 완전한 보호는 가장 사적인 성역인 '내 집' 안에 존재한다"** 는 본질적 진리를 주거 미학으로 복원합니다.
* **Parang-Sê가 정의하는 본질** : 작품 속 파량새의 '희망'이나 '행복'이라는 관념적 상징을 넘어, 거친 외부 환경 현실과 대조를 이루는 절대적인 **내면의 평온(Inner Peace)** 과 흔들리지 않는 **궁극의 안식**을 공간화합니다.

### 💎 Sur Mesure: 오직 당신만을 위한 단 하나의 성역
Parang-Sê는 파랑새의 인문학적 성찰을 사적인 주거 공간의 미학으로 완벽히 투영합니다. 일상의 긴 여정 끝에 비로소 당도하는 나만의 성역. 그 안에서 세상의 모든 소요(騷擾)를 거르고 온전한 안식과 평온을 소유하게 하는 것—그것이 하이엔드 Sur Mesure 하우징 브랜드 Parang-Sê가 선사하는 가치입니다.

* **독점적 유일성**: 규격화된 기성 창호 제품을 엄격히 배제합니다.
* **정통 오더메이드**: 고객의 심미적 취향과 공간의 구조에 맞추어 1:1 전량 맞춤 독점 제작되는 최고급 **Sur Mesure(쉬르 므쥐르)** 시스템을 통해 컬러 유리와 고품격 시스템 창호를 마스터피스로 빚어냅니다.  
#### **Parang-Sê** 프레임은 세상의 소음을 지우고 가혹한 날씨마저 하나의 풍경으로 치환합니다. —이것이 Parang-Sê가 지향하는 하우징 미학입니다.
